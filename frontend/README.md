


## Setup/Installs

```cd frontend```

- First install node.js
- You might need to run `npm install next`

## Getting Started

First, run the python backend. You need to `cd backend` and then `.\venv.\Scripts\activate` and then start the backed with:

```bash
uvicorn main:app --reload
```

To start the frontend open another terminal (do not kill the backend one), `cd frontend` and then:

```bash
npm run dev
```

Open [http://localhost:3000/Child-Testimony-App](http://localhost:3000/Child-Testimony-App) with your browser to see the result.
